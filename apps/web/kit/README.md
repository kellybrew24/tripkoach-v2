# Website UI kit (desktop)

Desktop is the secondary surface but fully supported. Designed at 1280px; the same components reflow to the
mobile kit below 768px.

| Screen | Covers |
| --- | --- |
| Browse | hero search, sticky sidebar filters, 3-up tour grid, sort, results count, pagination, loading and empty states |
| Tour detail | photo mosaic, highlights, itinerary/includes/policy accordion, sticky booking card with departure picker |
| Checkout | horizontal stepper with labels, two-column form plus sticky order summary, per-step back/continue, pay-later default |
| Confirmation | reference, status, booking recap, pay-later instructions |
| Account / bookings | account sidebar nav, status tabs, pending-payment banner, booking rows |

Layout rules: container 1200px max, 12-column grid, 24px gutters, 40px page margin at ≥1280px.
The bottom bar in `index.html` is a demo control, not part of the product.
