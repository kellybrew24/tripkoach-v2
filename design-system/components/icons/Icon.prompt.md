The only icon primitive — renders a Lucide outline glyph in currentColor; never hand-write an SVG in TripKoach UI.

```jsx
<Icon name="map-pin" size={16} />
<Icon name="circle-check-big" size={24} label="Confirmed" />
```

Icons always inherit text colour. Decorative icons next to a text label must stay unlabelled so screen readers do not read them twice.
